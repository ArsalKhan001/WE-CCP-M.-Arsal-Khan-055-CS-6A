PROJECT SETUP INSTRUCTIONS



Important Note
Due to GitHub file size limitations, the complete project has been uploaded in multiple compressed files instead of a single package.


Project Structure After Extraction
After extracting all files into the same directory, the project will contain the following folders:
•	frontend 
•	backend 
•	node_modules 
All folders must be placed inside the same root project directory.


How to Run the Project
1. Download all files
Download all ZIP files available in the repository.
2. Extract files
Extract all ZIP files into the same parent folder so that all project components are combined into a single directory structure.
3. Run the project
•	Start the backend server using the appropriate command defined in the backend project files. 
•	Start the frontend application using the appropriate command defined in the frontend project files. 
Refer to the respective folders for specific execution commands and configuration details.


Reason for Multiple Files
The project could not be uploaded as a single file because the total size exceeded GitHub’s file size limits. Therefore, it has been split into multiple compressed files for submission.
